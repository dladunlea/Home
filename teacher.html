🍎 Teacher Dashboard

Edit the sheet, and the class page updates itself

Each class page reads its own Google Sheet (Student View tab, published to the web as CSV). Edits show up on the page within about 5 minutes. Nothing here needs a password: the sheets themselves only open for your Google account.

📅 Ahead or behind? Tap Change shift and type a number in the Shift cell: -1 = one class day behind, 1 = one ahead, 0 = on the plan. Today's checklist, topic and unit card move to that lesson. The date, warm-up, calendar, tests and due dates stay put. Set it back to 0 once you've caught up.
